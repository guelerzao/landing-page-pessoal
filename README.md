<h2 align="center">⟦ 01 · SOBRE O PROJETO ⟧</h2>

```yaml
projeto:      Landing page pessoal
objetivo:     "Apresentar quem eu sou, o que sei fazer e como falar comigo,
               em uma única página clara e rápida."
autor:        Augusto de Almeida Guelere
seções:       [Início, Sobre, Skills, Contato]
stack:        [HTML5, CSS3]
status:       Concluído · aceita melhorias
```

Página de apresentação com bio, skills e contato, feita para praticar estrutura semântica, layout responsivo e design com identidade própria, sem frameworks.

<!-- ░░░ RECURSOS ░░░ -->
<h2 align="center">⟦ 02 · RECURSOS ⟧</h2>

| Módulo | O que faz |
| --- | --- |
| 📱 Layout responsivo | Se adapta de celular a desktop com CSS Grid e Flexbox |
| 🧭 Navegação por âncoras | Menu leva direto a cada seção, com rolagem suave |
| ♿ Acessibilidade | HTML semântico, foco visível no teclado e respeito a `prefers-reduced-motion` |
| 🧩 Cartão de código | Resumo pessoal em formato de objeto JavaScript, direto no hero |
| 🪶 Zero dependências | Só HTML e CSS (as fontes vêm do Google Fonts) |

<h2 align="center">⟦ 04 · COMO RODAR ⟧</h2>

```bash
guelerzao@system:~$ git clone https://github.com/guelerzao/landing-page-pessoal.git
guelerzao@system:~$ cd landing-page-pessoal

guelerzao@system:~$ open index.html       # macOS
```
